A multimodal urban monitoring and emergency-response platform combining **audio, video, event intelligence, severity analysis, geospatial visualization, and routing** in a unified digital-twin environment.

<br/>

### Four-Tier Architecture

```text
┌─────────────────────────────────────────────┐
│             Flutter Desktop UI              │
│     Monitoring • Map • Events • History     │
└─────────────────────┬───────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────┐
│                Flask ML API                 │
│   Video • Audio • Fusion • Action Models    │
└─────────────────────┬───────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────┐
│          Node.js / Express Backend          │
│ Auth • Events • Routing • APIs • Uploads    │
└─────────────────────┬───────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────┐
│                  MongoDB                    │
│ Users • Events • Predictions • Locations    │
└─────────────────────────────────────────────┘
```

### Core Features

- Multimodal audio-video urban scene classification
- R(2+1)D-18 video classification
- PaSST and CNN-14 audio classification
- Cross-modal attention fusion
- Nine emergency-event categories
- Rule-based severity prioritization
- Action-recognition pipeline
- OpenStreetMap digital-twin visualization
- OSRM route generation
- JWT authentication
- Geospatial event storage
- First-responder dashboard
- Raspberry Pi edge-inference experimentation

</details>
